# vue-todo

Небольшое SPA-приложение на Vue (Vite), которое:
1. Загружает список задач из `tasks.json`.
2. Позволяет отмечать задачи как выполненные (чекбоксы).
3. Сохраняет состояние списка задач при перезагрузке страницы (используется `localStorage`).

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/vue-todo.git


2. Установите зависимости:
   npm install
   

3. Запустите сервер для разработки:
   npm run dev


4. Откройте в браузере http://localhost:5173.
